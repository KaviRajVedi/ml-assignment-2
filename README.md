# Tumour Classification Lab

## a. Problem statement
Compare five supervised classifiers for distinguishing malignant and benign breast
tumour samples using measurements of cell nuclei from digitized fine-needle aspirate
images. The experiment measures classification performance on one held-out partition
and exposes saved-model evaluation in a Streamlit app. It is educational, not a
clinical diagnostic system.

## b. Dataset description
Source: [UCI Breast Cancer Wisconsin (Diagnostic)](https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic),
loaded from scikit-learn's packaged copy using `load_breast_cancer(as_frame=True)`.

- 569 instances and 30 numeric input features; 212 malignant and 357 benign samples.
- Target: `0 = malignant` (positive class), `1 = benign`.
- Ten measurements (radius, texture, perimeter, area, smoothness, compactness,
  concavity, concave points, symmetry, fractal dimension), each summarized by mean,
  standard error and worst value. See the source dataset description for definitions.
- No missing values or duplicate rows in the packaged dataset, checked during preparation.
- Stratified 80/20 split with seed 17: 455 training and 114 test rows.
- Scaling is fitted only on training data for Logistic Regression, KNN and SVM;
  the fitted scaler is saved with the classifier. Tree and Gaussian NB use raw inputs.
- Fixed baseline hyperparameters were chosen before evaluation; no test-set tuning.

## d. Models used
| Model | Settings |
| --- | --- |
| Logistic Regression | StandardScaler; C=1; max_iter=2000; random_state=17 |
| Decision Tree | max_depth=5; min_samples_leaf=3; random_state=17 |
| KNN | StandardScaler; 5 neighbours; uniform weights; Euclidean distance |
| Naive Bayes | GaussianNB with default variance smoothing |
| Support Vector Machine | StandardScaler; RBF kernel; C=1; gamma=scale; probability=True; random_state=17 |

Accuracy and MCC use all predictions. Precision, recall and F1 use binary averaging
with malignant (`0`) as positive. AUC compares `target == 0` with the probability
column for class 0. Undefined precision/recall/F1 use zero. On a single-class upload,
AUC and MCC display N/A because a two-class comparison is unavailable.
The classification report separately shows both classes and macro/weighted averages.

## Run locally or on BITS Virtual Lab
Use Python 3.12 in the VM. Run from the repository directory:

```bash
python -m pip install -r requirements.txt
python prepare_data.py
python train.py
python -m streamlit run app.py
```

Open http://localhost:8501 in the VM browser. If installing into Anaconda base
fails, create a dedicated environment with `conda create -n ml-assignment python=3.12 -y`
and activate it with `conda activate ml-assignment` before installing.
Training prints the comparison, saves five complete pipelines and regenerates the
README results block. Uploads never invoke training. If artifact versions differ,
the app asks for matching requirements or an explicit offline training run.

## App features
- Upload a labeled test CSV or use/download the bundled 114-row test set.
- Choose any classifier and see six metrics, a labeled confusion matrix and report.
- Compare all five models on the same input rows; download metrics and predictions.
- Inspect class balance and feature summaries.
- All 30 feature columns and `target` are required; extra columns are ignored and
  column order is normalized. Non-numeric, missing, infinite and unknown target
  values are rejected, as are duplicate headers and empty data.
- Upload limit: 10 MB and 10,000 rows. One-class subsets show unavailable metrics explicitly.
